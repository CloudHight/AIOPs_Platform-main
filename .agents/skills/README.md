# AIOps Claude Skills

These project skills guide AI coding agents working on the AIOps platform.

## Skills included

- `terraform-aiops-platform` — Terraform-only AWS platform delivery.
- `jenkins-ci-cd` — Jenkins pipeline design and implementation.
- `sagemaker-modelops` — model training, validation, artifact publishing, and SageMaker endpoint handoff.
- `lambda-sam-to-terraform` — Lambda refactor and SAM-to-Terraform migration.
- `security-hardening` — IAM, secrets, network, scanning, encryption, and remediation safety.
- `observability-testing` — dashboards, alarms, unit tests, smoke tests, and synthetic anomaly validation.
- `incident-remediation` — anomaly lifecycle, Jira, SQS grace period, and automated remediation.
- `repo-refactor` — phased migration from the current repo structure to a senior structure.
- `project-documentation` — README, architecture docs, runbooks, and project-defense material.

Each skill is stored as `.claude/skills/<skill-name>/SKILL.md` so Claude Code can discover it as a project-level skill.
